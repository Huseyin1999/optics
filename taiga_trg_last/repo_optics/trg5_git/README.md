# Моделирование электроники триггера, шума ночного неба и клининга телескопов TAIGA-IACT (модуль trg5)

Модуль **trg5** выполняет физическое моделирование тракта электроники черенковских телескопов гамма-обсерватории **TAIGA-IACT**:
1. Считывание фотоэлектронов из бинарного файла оптической трассировки (`*_feb`);
2. Формирование сигналов в быстром тракте электроники и выработку кластерного триггера совпадений (`trigger_iact`);
3. Моделирование отклика медленного формирователя с субсплайновой интерполяцией формы импульса Акимы и интегрированием заряда в заданном временном окне;
4. Наложение пуассоновских флуктуаций ночного неба (Night Sky Background, NSB);
5. Двухпороговый хвостовой клининг изображений и вычисление параметров эллипса Хилласа (`cleaning`).

---

## 1. Сборка исполняемых C++ модулей

В актуальной версии программы модуль триггера `readbin_v4.cpp` содержит **собственную встроенную реализацию сплайнов Акимы**. Для компиляции **больше не требуются CERN ROOT или заголовочные файлы библиотеки GSL**.

### Быстрая сборка через Makefile
```bash
cd trg5_git
make
```
Команда собирает два исполняемых файла:
- `trigger_iact` — моделирование быстрого и медленного каналов электроники триггера;
- `cleaning` — двухпороговая очистка кадра и вычисление параметров Хилласа.

### Ручная компиляция
Если `make` недоступен, файлы компилируются стандартным `g++`:
```bash
# Модуль клининга (чистый C++11):
g++ -std=c++11 -O3 cleaning_corsika_pipeline.cpp -o cleaning -Wall

# Модуль триггера (C++11 + OpenMP для параллельной обработки):
g++ -std=c++11 -O3 readbin_v4.cpp -o trigger_iact -fopenmp
```

> [!NOTE]
> Если вам принципиально требуется сборка с библиотекой CERN ROOT (через `TSpline3`), доступна отдельная цель:
> `make trigger_root` (требует доступный `root-config` и библиотеку `libMathMore`).
> Для распределённых расчётов на кластере HTCondor настоятельно рекомендуется стандартная сборка `make` (без внешних зависимостей).

## 2. Режимы использования

### Режим А: В составе сквозного конвейера HTCondor (`condor_pipeline`)
В производственном режиме запуск триггера осуществляется автоматически скриптом `run_trg_step.py`:
- Скрипт написан на **чистом стандартном Python 3** и **не требует наличия `numpy` или `pandas` на рабочих узлах кластера**;
- Автоматически находит все калибровочные файлы внутри распакованного `runtime/`;
- Сжимает результаты в единый архив `PREFIX_trg.tar.gz` и извлекает итоговые таблицы параметров Хилласа `PREFIX_hillas_iact*.csv`.

### Режим Б: Автономный локальный запуск на сервере
Для автономной обработки предварительно сгенерированного файла `*_feb`:
```bash
# Запуск через оркестратор:
python3 optics_trigger_pipline.py configs/trigger_config.json /path/to/event_feb

# Либо через универсальный run_trg_step.py:
python3 ../condor_pipeline/run_trg_step.py \
    --feb-file /path/to/event_feb \
    --config-file configs/trigger_config.json \
    --runtime-dir . \
    --output-prefix ./results/my_event
```

## 3. Каталог калибровочных данных (`Calibration/`)

В папке `Calibration/` содержатся физические константы, развёртки импульсов и калибровки детекторов:

1. **Формы импульсов медленного формирователя**:
   - `Calibration/slow_pulse_iact2_new` — калиброванная форма импульса для камер со **считыванием всей камеры** (full-camera readout, окно интегрирования 80 нс);
   - `Calibration/slow_pulse_cam1_old.txt` — форма импульса для камер со **считыванием с подхватом** (cluster-pickup readout, окно 48 нс).
2. **Координатные сетки фокальной плоскости (`coord_files`)**:
   - `XY_turn_2020jan2tel_18fix.txt` — актуальная координатная сетка камер TAIGA-IACT (с 2020 года);
   - `xy_turn_2019s_EP.txt` — сетка ранних сезонов IACT01.
3. **Коэффициенты относительной чувствительности ФЭУ (`factors_path`)**:
   - `factors_iact2_310120.led.txt`, `iact01_051019.factors` и др.
4. **Спектр одноэлектронных амплитуд (`amplitudes_file`)**:
   - `probablies8.txt` — распределение амплитуд одноэлектронных импульсов ФЭУ XP1911 с учётом динодной системы и вероятности послеимпульсов (~198 МБ).

### Подробное описание ключевых параметров

| Параметр | Описание |
| :--- | :--- |
| `IACTs` | Список моделируемых телескопов (от 1 до 5). Координаты телескопов на полигоне: IACT01: (108.5, 91.3), IACT02: (-35.5, -197.2), IACT03: (329.6, -361.2), IACT04: (210.0, -139.0), IACT05: (419.9, 23.5) метров. |
| `trigger_type` | `0` — режим считывания «с подхватом» сработавших кластеров; `1` — режим считывания всей камеры (560/595 пикселей). |
| `integrate_window` | Длительность временного окна интегрирования медленного канала (нс). Жестко связано с типом триггера: `48` нс для `trigger_type=0`, `80` нс для `trigger_type=1`. |
| `sense_cam` | Интегральный поправочный коэффициент оптической чувствительности телескопа к черенковскому свету по сезонам наблюдений (учитывает старение зеркал и световодов). |
| `background_params` | Моделирование гауссовых флуктуаций ночного неба (NSB). Параметр `std` задаёт среднеквадратичное отклонение шума ($\sigma_{\mathrm{NSB}}$) в фотоэлектронах. |
| `clean_edge1`, `clean_edge2` | Пороги двухпорогового клининга кадра ($q_{\mathrm{core}} / q_{\mathrm{boundary}}$), обычно $6.0 / 3.0$ или $5.0 / 2.5$ фотоэлектронов. |
| `use_brightest_island` | `1` — оставлять в кадре только наибольший связный кластер пикселей (остров изображения ШАЛ), удаляя изолированные флуктуации шума. |

| Сезон | Телескоп | sense_cam | Конус Уинстона | Sigma ($\sigma_{\mathrm{NSB}}$, п.э.) |
| :---: | :---: | :---: | :---: | :---: |

## 5. Выходные данные и параметры Хилласа

После этапа клининга формируются таблицы параметров формы черенковского изображения:
- **`Size`** — суммарный заряд очищенного изображения (в фотоэлектронах), пропорционален первичной энергии частицы;
- **`Length`** — большая полуось эллипса (продольное развитие каскада в атмосфере);
- **`Width`** — малая полуось эллипса (поперечный размер ливня; ключевой параметр для разделения гамма-квантов и протонов);
- **`Dist`** — расстояние от центра камеры до центра тяжести изображения;
- **`Alpha`** — угол между главной осью эллипса и направлением на исследуемый астрофизический источник;
- **`Azwidth`** — азимутальная ширина изображения;
- **`x_dist`, `y_dist`, `phi`** — координаты центра тяжести и угол ориентации эллипса в камере.

## 6. Диагностика и устранение проблем

1. **`FileNotFoundError: Cannot resolve asset: 'Calibration/slow_pulse_iact2_new'`**:
   - Файл `slow_pulse_iact2_new` не имеет расширения `.txt`. Убедитесь, что скрипт упаковки `pack_runtime.py` скопировал его в архив `runtime.tar.gz`. В актуальной версии скрипта этот файл включается принудительно.
2. **`ModuleNotFoundError: No module named 'numpy'` на удалённом узле**:
   - Убедитесь, что для запуска триггера используется актуальный скрипт `run_trg_step.py`, не зависящий от `numpy` и `pandas`.
3. **Ошибка компиляции `gsl/gsl_spline.h: No such file or directory`**:
   - Не используйте сторонние флаги `-DUSE_GSL`. Выполните сборку командой `make` или `g++ -std=c++11 -O3 readbin_v4.cpp -o trigger_iact -fopenmp`. Встроенная реализация сплайна Акимы не требует внешних библиотек.
