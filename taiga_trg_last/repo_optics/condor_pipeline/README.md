# Производственный запуск TAIGA-IACT (Конвертация + Оптика + Триггер) через HTCondor

Автоматизированный сквозной расчёт полного цикла моделирования: один исходный CORSIKA-файл — одна задача — один CPU.

```text
CORSIKA -> hybrid -> промежуточный _i -> TAIGA_optics_file -> промежуточный _feb -> trg5 (триггер + NSB + клининг) -> Hillas CSV
                                       (внутри одной временной папки scratch рабочего узла)
```

## Документация

В проект включены две версии руководства:
- **[README_FULL.md](README_FULL.md)** — **Полное руководство**: детальное научное и физическое описание работы всех программ комплекса (CORSIKA, конвертер `hybrid`, оптическая трассировка `TAIGA_optics`, электроника триггера `readbin_v4`/`trigger_iact`, наложение шума ночного неба `add_background`, двухпороговый клининг кадра и расчёт параметров Хилласа `cleaning`).
- **[README_QUICKSTART.md](README_QUICKSTART.md)** — **Краткое руководство**: выжимка команд для быстрой компиляции модулей, сборки `runtime.tar.gz`, создания контейнера Apptainer/Singularity, пошаговой отправки заданий в HTCondor и мониторинга очередей.

---

## Краткий обзор сквозного конвейера

1. **Единый проход без промежуточных файлов на диске**:
   Рабочий узел HTCondor получает только CORSIKA-файл и архив `runtime.tar.gz`. Промежуточные файлы `_i`, `_t` и бинарный `.feb` создаются в локальном scratch и удаляются по ходу работы (если не передан флаг `--keep-feb`).
2. **Результаты расчёта**:
   На submit-сервер возвращаются:
   - `PREFIX_trg.tar.gz` — архив очищенных событий и данных триггера;
   - `PREFIX_hillas_iact0*.csv` — итоговые таблицы параметров формы Хилласа для гамма/адронного разделения;
   - `PREFIX_A_sums2` — диагностика оптического моделирования;
   - `PREFIX.done` — криптографический маркер успешного завершения.

## Быстрый старт

```bash
# 1. Подготовка тестовой кампании на 1 событие
python3 prepare_run.py /path/to/corsika_data "$HOME/taiga_runs/test01" \
    --limit 1 \
    --radius 100

# 2. Переход в папку кампании и запуск
cd "$HOME/taiga_runs/test01"
condor_submit pipeline.sub

# 3. Мониторинг
condor_q
tail -f logs/*-0.out
```

Подробные инструкции по сборке `runtime.tar.gz` с файлом одноэлектронных амплитуд `probablies8.txt` и сборке контейнера приведены в **[README_QUICKSTART.md](README_QUICKSTART.md)**.
