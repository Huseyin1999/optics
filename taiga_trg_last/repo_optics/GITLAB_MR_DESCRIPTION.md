## Краткое резюме (TL;DR)

В данном Merge Request реализована полная сквозная интеграция модуля моделирования электроники триггера, шума ночного неба (NSB) и двухпорогового клининга кадра (**trg5**) в автоматизированный конвейер HTCondor (**condor_pipeline**).

Раньше вычисления требовали ручного разделения на две стадии, генерации промежуточных бинарных файлов размером в гигабайты (`*_feb`), наличия тяжеловесных библиотек CERN ROOT, GSL и Python-библиотек (`numpy`, `pandas`) на всех узлах грида.

Теперь весь цикл моделирования (**CORSIKA $\rightarrow$ hybrid $\rightarrow$ TAIGA_optics $\rightarrow$ trigger_iact $\rightarrow$ add_background $\rightarrow$ cleaning $\rightarrow$ Hillas CSV**) выполняется **внутри одной задачи HTCondor на одном процессорном ядре**, без внешних зависимостей на рабочих узлах и с автоматической очисткой временных файлов.

## 1. Проблемы и предпосылки

До проведения данной работы моделирование полного тракта телескопов TAIGA-IACT сталкивалось со следующими критическими ограничениями:

1. **Разрыв пайплайна и колоссальный оверхед по диску:**
   - Оптическое моделирование и триггер запускались раздельно.
   - Для каждого события на диск записывался промежуточный бинарный файл `*_feb` (до 2–5 ГБ на событие ШАЛ высокой энергии). При кампаниях на десятки тысяч событий это приводило к исчерпанию дискового пространства пулов и огромной нагрузке на сетевую файловую систему (NFS/Lustre).
2. **Зависимость от CERN ROOT и GSL-заголовков:**
   - Модуль `trigger_iact` использовал классы `TSpline3` из ROOT или заголовочные файлы GNU Scientific Library (`gsl/gsl_spline.h`) для интерполяции формы импульса формирователя. На гетерогенных рабочих узлах кластеров (ОИЯИ, МГУ, ИЯИ) библиотеки ROOT и заголовочные файлы `*-devel` часто отсутствуют, что приводило к сбоям компиляции и вылетов задач.
3. **Отсутствие Python-пакетов на узлах грида (`ModuleNotFoundError: No module named 'numpy'`):**
   - Рабочие слоты HTCondor предоставляют минимальное базовое окружение ОС (Enterprise Linux 7/8/9). Присутствие `numpy` или `pandas` не гарантируется. Задачи аварийно завершались с ошибкой импорта модулей.
4. **Непереносимые пути и потеря файлов без расширения:**
   - В старых скриптах `trg4` использовались захардкоженные абсолютные пути вида `/k38/taiga_pool/iact_trigger/...`.
   - Файл калибровки формы импульса `Calibration/slow_pulse_iact2_new` не имеет расширения `.txt` и отфильтровывался стандартными скриптами сборки, приводя к `FileNotFoundError`.

## 2. Реализованные технические решения

### 2.1. Встроенный субсплайновый алгоритм Акимы в C++ (`readbin_v4.cpp`)
- Разработана и встроена легковесная, автономная математическая модель интерполяции Акимы (Akima sub-spline) непосредственно в `readbin_v4.cpp`.
- Алгоритм Акимы устойчив к локальным выбросам и осцилляциям производных, гарантируя физически строгое и гладкое восстановление формы черенковского импульса.
- **Результат:** Исполняемый файл `trigger_iact` собирается чистым компилятором `g++ -std=c++11 -O3 -fopenmp` без единого вызова ROOT или GSL.

### 2.2. Архитектура нулевых зависимостей в Python (`run_trg_step.py`)
- Скрипт оркестрации этапа триггера `run_trg_step.py` полностью переписан с использованием **исключительно стандартной библиотеки Python 3** (`math`, `csv`, `json`, `os`, `sys`, `pathlib`, `struct`).
- Чтение конфигураций, конвертация форматов, подготовка аргументов и извлечение таблиц параметров Хилласа работают без `numpy` и `pandas`.
- Реализован робастный многоуровневый алгоритм поиска калибровочных файлов (`resolve_asset_path`), находящий файлы независимо от глубины вложенности в каталоге `runtime/assets`.

### 2.3. Сквозной конвейер и очистка scratch на лету (`pipeline_one.sh`)
- В скрипт `pipeline_one.sh` интегрирована цепочка вызова триггера и клининга.
- Промежуточные файлы конвертера `intermediate_i` и `intermediate_t` удаляются сразу после завершения оптического шага.
- Файл `result_feb` по умолчанию обрабатывается в оперативной памяти/локальном scratch и удаляется перед трансфером результатов на submit-сервер (`--keep-feb 0`).
- На submit-сервер возвращается компактный архив `*_trg.tar.gz` (содержащий очищенные события и CSV с параметрами Хилласа), лог оптики `*_A_sums2` и маркер успешности `*.done`.

### 2.4. Комплексная упаковка окружения (`pack_runtime.py`)
- Добавлены флаги для явного включения модулей триггера, калибровочных каталогов и крупного файла одноэлектронных амплитуд `probablies8.txt` (~198 МБ):
  - `--trigger`, `--cleaning`, `--trg-scripts`, `--trg-assets`, `--amplitudes-file`.
- Автоматически упаковываются бинарные библиотеки (`libtaiga_io_eventio.so`, `libtaiga_io_text.so`, `libgsl.so.25`, `libgslcblas.so.0`), обеспечивая независимость от установленных в ОС пакетов.

## 3. Сравнение «До» и «После»

| Параметр | До оптимизации | После интеграции (MR) |
| :--- | :--- | :--- |
| **Количество этапов запуска** | 2 раздельных запуска (оптика отдельно, триггер отдельно) | **1 сквозной запуск в HTCondor** |
| **Зависимости C++ для триггера** | CERN ROOT (`libMathMore`) или заголовочные файлы GSL | **Чистый C++11 + OpenMP (0 внешних библиотек)** |
| **Зависимости Python на узлах** | `numpy`, `pandas`, `tqdm`, `scipy` | **Чистый Python 3 Standard Library** |
| **Занимаемое место на задачу** | 3 – 7 ГБ (хранение исходных `_feb`) | **~10 – 30 МБ (сжатый научный результат `_trg.tar.gz`)** |
| **Сетевой трафик на ноду** | Передача гигабайтных `_feb` между серверами | **Только входной CORSIKA + `runtime.tar.gz`** |
| **Устойчивость к сбоям путей** | Падение при отсутствии точных абсолютных путей `/k38/...` | **Автоматический поиск ассетов в `runtime/`** |

## 5. Инструкция для воспроизведения и запуска

### 5.1. Сборка архива `runtime.tar.gz`
```bash
cd condor_pipeline
python3 pack_runtime.py \
    --hybrid ../io_taiga/hybrid \
    --optics ./TAIGA_optics_file \
    --assets ./runtime/assets \
    --library ../runtime/lib/libtaiga_io_eventio.so \
    --library ../runtime/lib/libtaiga_io_text.so \
    --library ../runtime/lib/libgsl.so.25 \
    --library ../runtime/lib/libgslcblas.so.0 \
    --trigger ../trg5_git/trigger_iact \
    --cleaning ../trg5_git/cleaning \
    --trg-scripts ../trg5_git \
    --trg-assets ../trg5_git \
    --amplitudes-file ../trg5_git/probablies8.txt \
    --output runtime.tar.gz
```

### 5.2. Запуск тестового события в HTCondor
```bash
python3 prepare_run.py /path/to/corsika_data "$HOME/taiga_runs/test_mr" --limit 1 --radius 100
cd "$HOME/taiga_runs/test_mr"
condor_submit pipeline.sub
```
