# Интеграция триггерного моделирования TAIGA-IACT (trg5) в condor_pipeline

План интеграции модуля моделирования триггера, фона ночного неба и клининга (`trg5_git`) в производственный конвейер HTCondor (`condor_pipeline`) в отдельной Git-ветке с созданием двух версий документации (полной и краткой практической).

## Согласованные решения и параметры (User Review)

> [!IMPORTANT]
> На основе последних требований пользователя план дополнен следующими ключевыми положениями:

- **Изоляция в отдельной Git-ветке**: Все изменения вносятся в отдельную ветку (`feature/trg5-pipeline-integration`). Исходное состояние оригинальной ветки (`main`/`master`) остаётся полностью сохранённым.
- **Две версии документации**:
  1. `README_FULL.md` (полная версия): исчерпывающее физическое и алгоритмическое описание работы всех звеньев конвейера (CORSIKA, `hybrid`, `TAIGA_optics`, `readbin_v4`/`trigger_iact`, `add_background`, `cleaning_corsika_pipeline`/Hillas, архитектура HTCondor).
  2. `README_QUICKSTART.md` (краткая версия): выжимка команд и инструкций — как скомпилировать программы, как упаковать `runtime.tar.gz` (включая контейнеризацию), как запускать кампанию через `prepare_run.py` и `condor_submit`, а также контролировать задачи.
- **Глубина цепочки обработки**: Полный цикл внутри каждого задания HTCondor (`CORSIKA -> hybrid -> TAIGA_optics -> trigger_iact -> add_background -> cleaning/Hillas`).
- **Управление промежуточными FEB-файлами**: Сохранение `.feb` файлов управляется опциональным флагом (`--keep-feb`). По умолчанию тяжёлый `.feb` удаляется на воркере после работы триггера.
- **Крупный файл амплитуд (`probablies8.txt`)**: Упаковывается через флаг `--amplitudes-file` в `pack_runtime.py`, попадает в `runtime.tar.gz` внутри `runtime/assets/trg5/probablies8.txt` и разрешается по относительному пути.

## 1. Обзор и целевая концепция

### Что делает обновлённый пайплайн
Создаётся непрерывная цепочка автоматизированного расчёта на кластере HTCondor:
```text
CORSIKA (*.corsika)
     │
     ▼
[ hybrid ] ────────────────► промежуточные _i и _t (локальный scratch воркера)
     │
     ▼
[ TAIGA_optics_file ] ─────► промежуточный result_feb (локальный scratch)
     │
     ▼
[ trigger_iact ] ──────────► отбор совпадений по порогу и временному окну (_c.txt)
     │                       (использует probablies8.txt и калибровки)
     │
     ▼
[ add_background ] ────────► наложение шума ночного неба NSB (_cb0.txt)
     │
     ▼
[ cleaning ] ──────────────► двухпороговый клининг кадра и расчёт параметров Хилласа
     │
     ├─────────────────────► *_clean_*.txt (очищенные амплитуды пикселей)
     ├─────────────────────► *_hillas_*.csv (параметры Хилласа: Size, Length, Width, Dist...)
     ├─────────────────────► *_feb (опционально, только если включен --keep-feb)
     └─────────────────────► result.done + диагностика (_A_sums2)
```

## 2. Архитектура и структура компонентов

### Системная диаграмма взаимодействия компонентов

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│                            Submit-сервер (HTCondor)                          │
│                                                                              │
│  pack_runtime.py                                                             │
│    └── Упаковывает: hybrid + optics + trigger_iact + cleaning +              │
│                     Calibration/* + probablies8.txt -> runtime.tar.gz        │
│                                                                              │
│  prepare_run.py / campaign.json                                              │
│    ├── Формирование jobs.tsv (список CORSIKA-входов)                         │
│    ├── Проверка runtime.tar.gz и настроек триггера                           │
│    └── Генерация pipeline.sub (описание ресурсов, трансфер файлов)           │
└──────────────────────────────────────┬───────────────────────────────────────┘
                                       │ condor_submit
                                       ▼
┌──────────────────────────────────────────────────────────────────────────────┐
│                        Рабочий узел HTCondor (Worker Scratch)                │
│                                                                              │
│  pipeline_one.sh:                                                            │
│  ┌────────────────────────────────────────────────────────────────────────┐  │
│  │ 1. Распаковка runtime.tar.gz, экспорт LD_LIBRARY_PATH                  │  │
│  │ 2. ./runtime/bin/hybrid input intermediate radius                      │  │
│  │ 3. ./runtime/bin/TAIGA_optics_file --input intermediate_i -> result_feb│  │
│  │ 4. Запуск модуля trg5 (локальный runner run_trg_step.py):              │  │
│  │    ├── trigger_iact (отбор фотоэлектронов с probablies8.txt)           │  │
│  │    ├── add_background (шум ночного неба NSB)                           │  │
│  │    └── cleaning (выделение образов и расчёт параметров Hillas)         │  │
│  │ 5. Если --keep-feb выключен -> удаление intermediate_*, result_feb     │  │
│  │ 6. Упаковка результатов триггера и Hillas                              │  │
│  │ 7. Запись job_key в result.done                                        │  │
│  └────────────────────────────────────────────────────────────────────────┘  │
└──────────────────────────────────────┬───────────────────────────────────────┘
                                       │ Возврат результатов (ON_EXIT)
                                       ▼
┌──────────────────────────────────────────────────────────────────────────────┐
│                          Каталог результатов (results/)                      │
│                                                                              │
│   PREFIX_hillas_iact0X.csv      (физические параметры черенковских ливней)   │
│   PREFIX_clean_iact0X.txt       (очищенные амплитуды пикселей)               │
│   PREFIX_cb0_iact0X.txt         (амплитуды с наложенным фоном NSB)           │
│   PREFIX_A_sums2                (оптическая диагностика)                     │
│   PREFIX_feb                    (только при передаче флага --keep-feb)       │
│   PREFIX.done                   (криптографический маркер завершения)        │
└──────────────────────────────────────────────────────────────────────────────┘
```

## 3. Детальный план реализации по шагам

### Шаг 1. Создание изолированной Git-ветки
- В репозитории создаётся ветка `feature/trg5-pipeline-integration`.
- Оригинальная ветка сохраняется без каких-либо изменений.

### Шаг 2. Адаптация триггерного кода (`trg5`) под относительные пути
- Устранение жёстких путей (`/media/...`, `/k38/...`) в `trigger_config.json` и Python-скриптах.
- Создание легковесного модуля запуска для воркера (`condor_pipeline/run_trg_step.py`):
  - Приём входного `.feb`-файла из scratch.
  - Подстановка актуальных путей к калибровкам и `probablies8.txt` из распакованного `runtime/assets/trg5/`.
  - Последовательный вызов `trigger_iact`, `add_background` и `cleaning`.
  - Формирование результирующих файлов с префиксом задания.

### Шаг 3. Модернизация упаковщика runtime (`pack_runtime.py`)
- Добавление параметров:
  - `--trigger-bin` (путь к скомпилированному `trigger_iact`),
  - `--cleaning-bin` (путь к `cleaning`),
  - `--amplitudes-file` (путь к `probablies8.txt`),
  - `--trg-assets` (путь к каталогу `Calibration/` и конфигам).
- Проверка зависимостей через `ldd` и упаковка всех необходимых библиотек в `runtime/lib/`.
- Поддержка создания контейнера/окружения (Apptainer / Singularity definition file `taiga_runtime.def` для сред, где системный Python/библиотеки изолированы).

### Шаг 4. Модификация воркера (`pipeline_one.sh`) и сабмита (`pipeline.sub`)
- Встраивание триггерного этапа после оптики в `pipeline_one.sh`.
- Поддержка аргумента сохранения `.feb` (`KEEP_FEB=0` или `KEEP_FEB=1`).
- Обновление `pipeline.sub` для корректного переноса выходных файлов (Hillas CSV, Clean TXT, маркер `.done`).

### Шаг 5. Обновление генератора кампаний (`prepare_run.py`)
- Добавление флагов `--keep-feb` и `--trigger-config`.
- Обновление проверки маркера завершения (`.done` проверяет наличие итоговых таблиц Хилласа).

### Шаг 6. Создание двух версий документации

#### 1. `condor_pipeline/README_FULL.md` (Полное научное и техническое руководство)
- **Физика и архитектура конвейера**:
  - Этап CORSIKA -> `hybrid`: разделение ливня на IACT и широкоугольные детекторы, генерация потока черенковских фотонов на уровне наблюдения.
  - Этап `TAIGA_optics`: сегментированное зеркало, учёт углов ориентации, расфокусировки, конусов Винстона, спектральной чувствительности и генерация фотоэлектронов (`.feb`).
  - Этап `trg5` (электроника и триггер):
    - Спектр одноэлектронных амплитуд ФЭУ XP1911 с учётом послеимпульсов (`probablies8.txt`).
    - Быстрый формирователь импульсов и временная сетка `t_grid`.
    - Логика совпадений соседних пикселей в окне `trig_window` (15 нс) выше порога `trig_amp` с учётом мертвого времени/холда кластеров `t_hold`.
    - Медленный формирователь, интерполяция Акимы и интегрирование заряда в окне `integrate_window`.
    - Моделирование шума ночного неба (NSB) в `add_background`.
    - Двухпороговый клининг (tail-cut) и расчёт моментов Хилласа (Size, Length, Width, Dist, Alpha, Azwidth, Miss) для идентификации первичных частиц.
  - Устройство пакета HTCondor, структура `campaign.json`, jobs.tsv и механизм идемпотентности через `.done`.

#### 2. `condor_pipeline/README_QUICKSTART.md` (Краткая практическая инструкция)
- **Сборка программ**:
  - Быстрая компиляция `TAIGA_optics`, `trigger_iact`, `cleaning`.
  - Сборка `runtime.tar.gz` одной командой через `pack_runtime.py` с указанием пути к `probablies8.txt`.
  - Сборка и запуск в контейнере (Apptainer / Singularity).
- **Быстрый запуск на HTCondor**:
  - Тестовый запуск на 1 событии (`--limit 1`).
  - Массовый производственный запуск.
  - Использование флагов `--keep-feb`, `--force`, `--radius`.
- **Мониторинг и диагностика**:
  - Просмотр очереди `condor_q`, логов ошибок и повторный запуск незавершённых задач.

## 4. Результаты работы этапа

По завершении реализации будут созданы/изменены:
1. Ветка Git: `feature/trg5-pipeline-integration`.
2. `condor_pipeline/pack_runtime.py` — упаковка триггера, калибровок и файла `probablies8.txt`.
3. `condor_pipeline/run_trg_step.py` — автономный runner триггерного цикла без абсолютных путей.
4. `condor_pipeline/pipeline_one.sh` — сквозной скрипт исполнения задания на рабочем узле.
5. `condor_pipeline/prepare_run.py` — CLI с поддержкой `--keep-feb` и триггерных настроек.
6. `condor_pipeline/pipeline.sub` — файл спецификации задач HTCondor.
7. `condor_pipeline/container/taiga_runtime.def` — рецепт контейнера Apptainer/Singularity.
8. `condor_pipeline/README_FULL.md` — исчерпывающее руководство.
9. `condor_pipeline/README_QUICKSTART.md` — краткая инструкция по сборке, контейнеру и запуску.
